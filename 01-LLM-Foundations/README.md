# Month 1 — LLM Foundations

## Objective

Develop a practical understanding of modern Large Language Models and build the first working LLM application.

## Week 1

- Transformer architecture
- Tokens and tokenization
- Context windows
- Introduction to embeddings

## Week 2

- Python and LLM APIs
- Prompt structure
- System and user messages
- Model parameters

## Week 3

- Embeddings
- Semantic similarity
- Document processing
- Vector representations

## Week 4

Build:

PDF Q&A Assistant with Citations

## Month 1 Deliverable

A working Python application capable of:

1. Reading PDF documents
2. Processing their content
3. Answering questions
4. Returning source references
